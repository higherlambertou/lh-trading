# 破產機率驗證 — 需求文件

> 給 Claude Code 實作參考
> 目標：用「賭徒破產問題」的數學框架，驗證現有資金配置在理論上的長期破產風險

---

## 背景與動機

現有策略的評估目前只看「期望值是不是正的」（回測勝率、獲利/虧損比），但「期望值為正」不代表長期不會破產——這是統計學上一個真實存在、且常被忽略的現象，叫「賭徒破產問題」（Gambler's Ruin）。

核心機制：**虧損有下限（本金歸零，遊戲結束），獲利沒有上限（可以一直玩下去）。即使每局期望值為正，只要讓策略「無限次、不設停損上限地」一直跑下去，統計上一定會出現一段「連續虧損」的壞運氣期——如果這段連續虧損的長度，剛好大到足以把本金燒完，策略就直接出局，不管「長期」來看本來應該賺錢。**

這跟單純看「期望值」或「勝率」完全是兩個不同的問題：期望值回答「平均而言划不划算」，破產機率回答「我有沒有足夠的本金，撐到那個平均數字真正顯現出來的那一天」。

---

## 理論公式（供參考，實際驗證時以模擬取代公式估算）

標準賭徒破產問題公式（固定下注金額、沒有設定獲利目標上限、純粹玩到破產或無限玩下去為止）：

```
P(破產) = (q/p)^i

p = 單局勝率
q = 1 - p（單局敗率）
i = 本金 ÷ 單筆下注金額（本金可以承受多少次連續最大虧損）
```

這個公式假設輸贏金額對稱（贏賠比1:1），實際策略的贏賠比不對稱時需要用更完整的公式，或者直接用歷史數據模擬（蒙地卡羅模擬）取代公式估算，會更貼近真實情況。

舉例（僅供理解機制，非實際數字）：本金1000元、單筆下注100元（i=10）、勝率55%——破產機率約13.7%。如果本金縮小到500元（i=5），破產機率會跳升到約37%；如果勝率只有52%（優勢更薄），破產機率會跳升到約44.8%。**破產機率對「本金相對單筆風險的比例」跟「勝率優勢大小」都高度敏感，一個小變化就會造成破產機率的巨大差異。**

## 需要做的事

### 第一步：整理現有策略的真實參數

針對現有 8 個策略（或優先挑 1-2 個主力策略），整理：

- 歷史勝率
- 平均獲利/平均虧損金額（贏賠比，不一定對稱）
- 目前實際投入的本金
- 單筆交易的最大可能虧損（換算停損點數成金額）

### 第二步：計算/模擬破產機率

- 如果贏賠對稱，可以直接套公式估算
- 如果贏賠不對稱（更貼近真實情況），建議用蒙地卡羅模擬：用歷史勝率跟贏賠比，隨機模擬數千次「連續交易直到本金歸零或達到某個長期目標」的過程，統計模擬出的破產比例
- 同時模擬不同本金規模下的破產機率（目前的本金、本金減半、本金加倍），看破產機率對本金規模的敏感度

### 第三步：對照「連續虧損的實際長度」

用歷史交易紀錄，找出實際發生過的最長連續虧損次數跟金額，跟模擬出的「理論上可能發生、導致破產的連續虧損長度」做對照，看現有本金規模夠不夠撐過歷史上已經出現過的最差情況。

## 待確認事項

- 要先確認目前實際投入的本金規模跟單筆風險曝險金額（這是計算的基礎輸入）
- 蒙地卡羅模擬需要決定模擬的交易局數上限（比如模擬未來1000筆交易）
- 如果計算出來的破產機率偏高，下一步可能需要調整本金規模或單筆風險比例，這部分可以之後再討論
