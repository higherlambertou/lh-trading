# 市場狀態判斷系統

> 在啟動任何策略之前，先判斷市場現在處於什麼狀態。
> 不同狀態用不同策略，不是在任何狀態下都用同樣的邏輯。

---

## 理論基礎

市場是一個複雜系統，有幾種不同的狀態：

```
趨勢狀態      價格有方向性，動量延續    →  順勢策略有優勢
均值回歸狀態  價格偏離後傾向回歸        →  逆勢策略有優勢
臨界點前      市場過於平靜，大波動接近  →  波動率策略有優勢
臨界點後      大波動已發生              →  單向策略有優勢
不明確        狀態混亂                  →  不操作
```

## 三層判斷架構

### 第一層：Hurst 指數（中長期狀態）

**工具：hurst_analyzer.py（已有）**

```
H > 0.55    趨勢狀態    →  順勢策略（orb、scalp 偏趨勢方向）
H < 0.45    均值回歸    →  逆勢策略（vwap_revert、scalp 偏反向）
H ≈ 0.5     隨機漫步    →  保守觀望，降低倉位
```

更新頻率：每天開盤前計算一次（用前 60 根 K 棒的滾動窗口）

---

### 第二層：隱含波動率（臨界點判斷）

**工具：需要新建 IV 監控模組**

```
IV 在歷史 20% 分位以下    市場過於平靜，大波動可能接近
                          →  考慮建立勒式（等待臨界點）

IV 在歷史 80% 分位以上    大波動已發生或正在發生
                          →  單向策略，不建跨式/勒式

IV 在中間區間             正常狀態
                          →  按第一層的 Hurst 狀態操作
```

資料來源：台指選擇權報價（需要從券商 API 或報價系統抓取）

計算方式：
```python
# IV 百分位計算
import numpy as np

def iv_percentile(current_iv, historical_iv, lookback=252):
    """
    current_iv      今天的 ATM 隱含波動率
    historical_iv   過去一年的每日 IV 列表
    lookback        回溯天數（預設一年）
    """
    recent = historical_iv[-lookback:]
    percentile = (np.sum(recent < current_iv) / len(recent)) * 100
    return percentile

# 判斷
def iv_signal(percentile):
    if percentile < 20:
        return "LOW", "考慮建勒式，等待大波動"
    elif percentile > 80:
        return "HIGH", "大波動狀態，考慮單向策略"
    else:
        return "NORMAL", "按 Hurst 狀態操作"
```

## 策略對應表

```
Hurst 狀態    IV 狀態    對應策略
趨勢          正常        scalp 偏順勢方向 + 考慮 orb
均值回歸      正常        scalp 偏逆勢方向 + 考慮 vwap_revert
任何          IV 低       建立勒式，等待大波動
任何          IV 高       事件已發生，考慮單向選擇權
不明確        任何        不操作，等待狀態清晰
```

## 每日操作流程

### 開盤前（09:00 前完成）

```
1. 執行 hurst_analyzer.py，取得今日 Hurst 指數
2. 查詢台指 ATM 選擇權報價，計算 IV 百分位
3. 對照策略表，確認今日操作模式
4. 記錄到每日日誌
```

### 盤中

```
按照開盤前確認的模式操作
不在盤中更改判斷（除非有重大事件）
```

### 收盤後

```
記錄今日結果
更新 Hurst 滾動窗口數據
```
