# 選擇權波段策略框架

> 補充現有 scalp 系統，捕捉 scalp 做不到的波段利潤

---

## 策略概覽

### 兩個獨立情境，不強行合併

```
情境一    主動建倉（IV驅動）
情境二    事件驅動（方向明確時）
特殊情況  事件發生時，兩個情境同時進行
```

---

## 情境一：主動建倉（跨式）

### 進場條件

```
IV 處於相對低位（歷史低點附近）
市場相對平靜、無明確方向
時間距離已知重大事件有一定緩衝
```

### 操作邏輯

```
買進跨式（Long Straddle）
  同時買相同執行價的 Call 和 Put
  同一到期日

等待大波動發生
  不預測方向
  讓市場告訴你往哪走
```

### 部位管理

```
方向明確後
  平掉虧損那一邊（損失已發生的部分）
  留下獲利那一邊繼續跑

出場條件
  波動發生，IV 大幅上升後獲利了結
  或到期前 X 天方向未明確，認賠時間耗損
```

### 成本結構注意事項

```
假設跨式成本 100 點（Call 50 + Put 50）
方向明確時 Put 跌到剩 20 點 → 平倉 Put，已虧 30 點
留下 Call，需要漲超過 80 點才真正回本

→  平倉時機越早，剩下那一邊的回本門檻越低
→  這是這個策略最關鍵的判斷點
```

---

## 情境二：事件驅動（單向）

### 觸發條件

```
有非常明確的方向性訊號
例如：
  美國重大關稅政策
  台股單日超過 1000 點的波動已經開始
  其他明確的宏觀事件
```

### 操作邏輯

```
直接買單向（Call 或 Put）
不需要跨式，方向已經明確

主要在夜盤操作
  美股開盤後（約 21:30）方向確認
  持有到凌晨 3-4 點收盤前平倉
```

### 歷史表現

```
之前做台指期貨的操作
波動持續幾個小時
後續波動幅度幾百到 1000+ 點
當天收盤前平倉
```

---

## 兩個情境同時進行（事件發生時）

```
平常持有跨式（情境一已建倉）
事件發生，方向明確

同時做兩件事：
  1. 平掉跨式中虧損的那一邊
     留下獲利的那一邊繼續跑

  2. 加碼單向部位（情境二）
     在方向確認後追加 Call 或 Put
```

---

## 關鍵風險

### Vega 風險（最重要）

```
在事件發生後買進（IV 已上升）
就算方向對，IV 下降會侵蝕利潤
這叫做「Vega 壓縮」

解法：
  情境一：在 IV 低的時候提前建倉，避開這個問題
  情境二：接受 Vega 風險，用波動幅度補回來
```

### 夜盤流動性

```
台指夜盤選擇權流動性差
買賣價差大，進出都有額外成本

需要驗證：
  換成選擇權後，流動性成本有多大？
  跟期貨相比，實際獲利有沒有被侵蝕？
```

### 時間耗損

```
跨式持有越久，時間價值流失越多
如果大波動遲遲不來，兩邊都在虧
→  需要設定最長持有時間，到期認賠
```

---

## 與現有 scalp 系統的關係

```
完全獨立的兩個系統
  scalp    短期訂單流不平衡，分鐘級
  選擇權   波段方向，小時到天級

不試圖互相對沖
  對沖需要精確計算 Delta，複雜度高
  兩個系統各自獨立評估績效

資金分開管理
  scalp 用原本帳戶
  選擇權波段用獨立資金
```

## 下一步行動

### 必須先做的驗證

```
把之前夜盤期貨操作的細節整理出來：
  進場時間和價位
  平倉時間和價位
  當時的市況（什麼事件、波動幅度）

回測問題：
  如果當時用選擇權做同樣的操作
  結果會不一樣嗎？
  流動性和 Vega 有沒有侵蝕掉優勢？
```

### IV 監控機制

```
需要建立一個方式追蹤台指選擇權的 IV
判斷什麼時候是「相對低位」
可以用歷史 IV 的百分位來判斷
  IV 在過去一年的 20% 分位以下  →  考慮建倉
  IV 在過去一年的 80% 分位以上  →  避免買跨式
```

### 關鍵判斷點需要定義清楚

```
什麼叫「方向明確」？
  需要一個客觀標準，不能靠感覺
  例如：台指夜盤移動超過 X 點，且持續 Y 分鐘

平倉時機的規則
  虧損那一邊跌到剩多少比例時平倉？
  這個比例決定了你的整體成本結構
```
